# 365일 묵상집 — 토스 미니앱 개발 요청서

> 문서 버전: v0.1 (초안) · 작성일: 2026-11-16
> 대상: 앱인토스(Apps in Toss) 미니앱 개발자 / 디자이너
> 참고 화면: `365_묵상_화면예시.html`

---

## 1. 프로젝트 개요

| 항목 | 내용 |
|---|---|
| 앱 이름(가칭) | **오늘의 말씀 365** |
| 원본 콘텐츠 | 교회 목사님이 집필한 365일 묵상집(종이책) — 일차별 성경 암송 구절 + 짧은 묵상글 |
| 만드는 이유 | 책이 두껍고 무거워 들고 다니기 어려움 → 휴대폰에서 매일 가볍게 읽고 기록 |
| 플랫폼 | 토스 앱 내 미니앱 (앱인토스, WebView 방식 권장) |
| 핵심 가치 | ① 오늘 읽을 분량이 바로 보인다 ② 시작일 기준으로 진도가 달력에 쌓인다 ③ 느낀점을 남긴다 |

### 1.1 목표
- 사용자가 **원하는 날짜를 1일차로 지정**하고, 그날부터 365일 동안 매일 한 편씩 묵상
- 매일 **암송 구절 + 묵상글**을 읽고, **느낀점**을 짧게 기록
- **달력**에서 시작일·완료일·오늘 위치를 한눈에 확인

### 1.2 범위 밖 (1차 버전 제외)
- 커뮤니티/댓글, 다른 사용자와 공유 피드
- 오디오 낭독, 다국어
- 결제/후원 기능

---

## 2. 사용자 & 시나리오

**주 사용자**: 교회 성도(30~70대), 매일 아침/출퇴근길에 짧게 묵상하는 사람

1. 토스에서 미니앱 진입 → 처음이면 **시작일 선택** 화면
2. 달력에서 날짜 선택(기본값: 오늘) → "이날이 1일차예요" 안내 → 시작
3. 홈에서 **오늘 N일차** 암송 구절과 묵상글 읽기
4. 하단 **"느낀점 쓰기"** → 작성·저장 → 해당 일차 완료 처리
5. **달력 탭**에서 지금까지 완료한 날, 놓친 날, 연속 기록 확인
6. 지난 날짜를 눌러 다시 읽거나 느낀점 수정

```
   └─ 상세: N일차 말씀 보기 / 느낀점 작성·수정
```

## 4. 화면별 상세 요구사항

### 4.1 온보딩 · 시작일 선택
- 큰 제목: "언제부터 시작할까요?"
- iOS 스타일 월 달력, 기본 선택값 = 오늘
- 선택 시 하단 요약 카드: `2026.11.16(월) 1일차 → 2027.11.15(월) 365일차`
- 하단 고정 CTA 버튼 "이 날부터 시작하기"
- 과거 날짜 선택 허용 (이미 책으로 읽고 있던 사람 고려)

### 4.2 오늘 (홈)
- 상단: 날짜(작게) + **"23일차"** 라지 타이틀 + `/ 365`
- 진행률 바 또는 링 (23/365, 6%)
- **암송 구절 카드**: 성경 본문 + 출처(예: 시편 119:105). 카드 탭 시 "가리고 외우기" 모드(본문 블러 처리 후 탭으로 공개)
- **묵상 본문**: 책의 해당 일차 제목 + 본문, 가독성 좋은 줄간격(1.7) 
- 하단 고정 버튼: 느낀점 미작성 → "느낀점 쓰기" / 작성 완료 → "오늘 묵상 완료 ✓ · 수정하기"
- 좌우 스와이프 또는 화살표로 전/다음 일차 이동 (미래 일차는 잠금 여부 옵션 — 6장 참고)

### 4.3 느낀점 작성
- 상단에 오늘 암송 구절 한 줄 요약 고정
- 질문 프롬프트(선택): "오늘 말씀에서 마음에 남은 한 단어는?"
- 멀티라인 입력창, 글자수 표시(최대 1,000자)
- 감정 태그 칩(선택): 감사 · 평안 · 회개 · 결단 · 위로 · 기도제목
- 저장 시 해당 일차 `완료` 처리 + 가벼운 햅틱/토스트 "23일차 묵상을 기록했어요"

### 4.4 달력
- 월 단위 달력, 좌우 스와이프로 월 이동
- 날짜 셀 표시 규칙

| 상태 | 표시 |
|---|---|
| 시작일(1일차) | 셀 위 작은 라벨 "시작" + 테두리 강조 |
| 완료(느낀점 작성) | 채워진 원(액센트 컬러) |
| 읽기만 함 | 옅은 원 |
| 놓친 날 | 표시 없음 (회색 숫자) |
| 오늘 | 굵은 숫자 + 링 |
| 시작 전 / 365일 이후 | 비활성(흐린 회색) |

- 날짜 아래 작은 글씨로 일차 표시(예: `23`) 옵션
- 상단 통계 카드: 완료 일수 · 연속 기록(streak) · 남은 일수
- 날짜 탭 → 해당 일차 상세로 이동

### 4.5 기록 (느낀점 모아보기)
- 카드 리스트: `23일차 · 11.16` / 구절 출처 / 느낀점 2줄 미리보기 / 태그
- 상단 검색, 태그 필터

### 4.6 설정
- 시작일 변경 (경고: "일차 계산이 바뀌어요. 기존 기록은 유지돼요")
- 매일 알림 시간 (토스 푸시/알림 API 사용 가능 여부 확인 필요)
- 글자 크기 (보통 / 크게 / 아주 크게) — 장년층 고려 필수
- 데이터 내보내기(텍스트) / 초기화

## 5. 디자인 가이드

### 5.1 콘셉트
**"조용하고 깨끗한 아침"** — iOS 기본 앱(메모, 건강, 캘린더) 같은 절제된 UI. 장식보다 여백과 타이포그래피로 세련됨을 만든다.

### 5.2 타이포그래피
```css
font-family: -apple-system, BlinkMacSystemFont, "SF Pro Display",
             "Apple SD Gothic Neo", "Pretendard", system-ui, sans-serif;
```
- iOS 기기: SF Pro + Apple SD Gothic Neo 자동 적용
- Android 대비: **Pretendard** 웹폰트 fallback (SF와 톤이 가장 비슷한 한글 폰트)
- 암송 구절은 세리프 대비감 옵션: `"Noto Serif KR"` (선택)

| 용도 | 크기 / 굵기 |
|---|---|
| Large Title (N일차) | 34px / 700, letter-spacing -0.5px |
| Title | 22px / 700 |
| 본문 | 17px / 400, line-height 1.7 |
| 암송 구절 | 20px / 500, line-height 1.6 |
| 캡션 | 13px / 400, 회색 |

### 5.3 컬러

| 토큰 | 값 | 용도 |
|---|---|---|
| `--bg` | `#F2F2F7` | iOS grouped 배경 |
| `--card` | `#FFFFFF` | 카드 |
| `--label` | `#1C1C1E` | 기본 텍스트 |
| `--label-2` | `#8E8E93` | 보조 텍스트 |
| `--separator` | `#E5E5EA` | 구분선 |
| `--accent` | `#3182F6` | 토스 블루 (CTA, 완료 표시) |
| `--accent-soft` | `#E8F1FE` | 선택 배경, 읽기만 함 |
| `--warm` | `#F5EFE6` | 암송 카드 배경(종이 느낌) |

- 다크모드 지원 (iOS 시스템 다크 컬러 기준: 배경 `#000`, 카드 `#1C1C1E`)

### 5.4 컴포넌트 규칙
- 카드 radius 20px, 그림자 없이 배경 대비로 구분
- 버튼 높이 56px, radius 16px, 화면 하단 고정 + safe-area 대응
- 탭바: iOS 스타일 반투명(blur) 하단 탭
- 아이콘: SF Symbols 느낌의 라인 아이콘 (예: Lucide)
- 앱인토스 **TDS(Toss Design System)** 가이드와 충돌 시 TDS 우선 검토

## 6. 기능 로직

### 6.1 일차 계산
```ts
// 시작일 = 1일차
const dayIndex = differenceInCalendarDays(today, startDate) + 1; // 1 ~ 365
if (dayIndex < 1)   → "아직 시작 전이에요 (D-n)"
if (dayIndex > 365) → "365일 완주!" 화면
```
- 기준 시간대: `Asia/Seoul`, 자정 기준 일차 변경

### 6.2 진도 방식 (결정 필요 ⚑)
| 방식 | 설명 | 추천 |
|---|---|---|
| A. 날짜 기준 | 날짜가 지나면 일차도 자동 진행. 놓친 날은 달력에서 비어 보임 | ✅ 책과 동일한 경험 |
| B. 진도 기준 | 완료해야 다음 일차가 열림 | 꾸준함 강조 |

→ 1차 버전은 **A안**, 설정에서 B안 토글 옵션 검토

### 6.3 미래 일차 열람
- 기본: 오늘 이후 일차는 잠금(제목만 노출) / 옵션으로 해제 가능

### 6.4 완료 판정
- 느낀점 저장 = `완료`
- 본문을 끝까지 스크롤 = `읽음`

## 7. 데이터 구조

### 7.1 콘텐츠 (정적 JSON, 앱에 번들)
```json
{
  "day": 23,
  "title": "내 발의 등이요",
  "verse": {
    "ref": "시편 119:105",
    "text": "주의 말씀은 내 발에 등이요 내 길에 빛이니이다"
  },
  "body": "묵상 본문 …",
  "question": "오늘 내 길을 비추는 말씀은 무엇인가요?"
}
```
- 365개 항목, `content/days.json` 하나 또는 월별 분할
- 책 원고(한글/워드/PDF) → JSON 변환 스크립트 별도 작업

### 7.2 사용자 데이터
```ts
type UserState = {
  startDate: string;          // "2026-11-16"
  fontScale: 'md' | 'lg' | 'xl';
  reminderTime?: string;      // "07:00"
  records: Record<number, {   // key = day
    status: 'read' | 'done';
    note?: string;
    tags?: string[];
    updatedAt: string;
  }>;
};
```
- 1차: 기기 로컬 저장(앱인토스 Storage API 또는 localStorage)
- 2차: 토스 로그인 연동 후 서버 저장(기기 변경 대비)

## 12. 화면 예시
`365_묵상_화면예시.html` 파일을 브라우저에서 열면 아래 4개 화면을 볼 수 있습니다.

1. **시작일 선택** — 달력에서 1일차 지정

3. **느낀점 작성** — 질문 프롬프트 + 감정 태그
